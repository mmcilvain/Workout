# Workout Favorites

A small React/Vite workout library demo with local save/unsave behavior.

## Features

- Save and unsave workouts from the workout library.
- Persist saved workouts with `localStorage` across refreshes.
- Safely fall back to in-memory favorites if `localStorage` is unavailable.
- Show an empty state when no workouts have been saved yet.

## Scripts

```bash
npm install
npm run dev
npm run build
```
